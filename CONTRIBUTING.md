# Bidra

Använd Node-versionen i `.nvmrc` och `npm ci`. Håll ändringar fokuserade och kör `npm test`, `npm run build` samt `npm run test:browser` när spel- eller klientbeteende ändras. Uppdatera dokumentation när nätverksprotokoll, kontroller, kartdata eller sparformat ändras.

Lägg aldrig in hemligheter, `node_modules`, sparfiler, byggresultat eller lokala testartefakter i Git. Lägg till käll- och licensinformation för tredjepartstillgångar. Ändra inte offlineprofiler till en betrodd källa för multiplayerprogression.

Arbeta på en separat gren och använd pull request för fortsatta ändringar. Befintlig utcheckning i en isolerad molnuppgift räcker; skapa inte extra Git-worktrees om det inte efterfrågas. Projektägaren behöver välja licens innan projektet marknadsförs som öppet för återanvändning.
